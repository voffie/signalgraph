---
title: Generate
description: Generate a typed SignalGraph client from a project schema.
---

```sh
npx signalgraph generate
```

The CLI looks for `signalgraph.config.ts` in the working directory and its parents. It validates the schema exports and writes `index.ts` to `out`. On success, it prints the output path and the number of messages and consumers. Connect to the broker when you run the client.

## Watch and debug

```sh
npx signalgraph generate --watch
npx signalgraph generate --log-level debug
```

Use `--watch` or `-w` to regenerate after changes to the config or schema file. Restart the watcher if it exits after a generation error. Debug logging shows the resolved config, schema, and output paths.

## Common generation errors

- If no config is found, run the command from the project directory or add [signalgraph.config.ts](/config/).
- If the config cannot load as ESM, check for `"type": "module"` in the nearest `package.json`.
- If a consumer references an unexported message, export the message as a top-level declaration and have the consumer reference that exact declaration.
- If names collide after conversion to client property names, rename one declaration. For example, `orders.created` and `orders-created` both become `ordersCreated`.
