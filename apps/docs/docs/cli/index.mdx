---
title: CLI
description: Run the SignalGraph CLI from your project.
---

The `signalgraph` executable ships with the core package. Run it from your ESM project with `npx signalgraph` or `pnpm exec signalgraph`. A package script can also call `signalgraph` directly.

```sh
npx signalgraph generate
npx signalgraph --help
npx signalgraph --version
```

See [generate](/cli/generate/) for watch mode, output, and troubleshooting.
