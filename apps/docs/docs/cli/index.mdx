---
title: CLI
description: What is SignalGraph's CLI
---

SignalGraph ships a CLI along with the core package. The CLI allows SignalGraph to do a few things like generating the custom client.
Each command needs to run as a package.json script.

The CLI is built using Effect's CLI module and outside the commands it ships, the CLI has these commands:
- `generate` - Generates the custom SignalGraph client based on the schema and output options inside the config
