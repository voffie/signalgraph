---
title: Config
description: Set the schema file and generated client directory.
---

Place `signalgraph.config.ts` at the root of your ESM application and default-export a config. Both paths are resolved relative to the config file, even if you run the CLI from a subdirectory.

```ts title="signalgraph.config.ts"
import { defineConfig } from "signalgraph/config";

export default defineConfig({
  schema: "./src/schema/schema.ts",
  out: "./generated"
});
```

| Field | Purpose |
| --- | --- |
| `schema` | Path to the module that exports your [messages and consumers](/schema/). |
| `out` | Directory where the CLI writes `index.ts`. |

After changing either path, run [generate](/cli/generate/) again.
