---
title: Installation
description: Install SignalGraph, Effect, and the RabbitMQ adapter.
---

Use a Node.js ESM project. Set `"type": "module"` in its `package.json`. Use Node.js 22.19 or newer for the current CLI and its Effect Node dependencies.

Install Effect and SignalGraph. Add the RabbitMQ adapter in applications that publish or consume messages through RabbitMQ.

<CodeGroup>

```sh npm
npm install effect signalgraph @signalgraph/adapter-rabbitmq
```

```sh pnpm
pnpm add effect signalgraph @signalgraph/adapter-rabbitmq
```

</CodeGroup>

For the [quickstart](/getting-started/quickstart/), also install `tsx` to run the TypeScript files directly:

<CodeGroup>

```sh npm
npm install -D tsx
```

```sh pnpm
pnpm add -D tsx
```

</CodeGroup>

Next, follow the [quickstart](/getting-started/quickstart/) or go to the [config reference](/config/) if you already have a schema.
