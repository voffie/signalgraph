---
title: Installation
description: Install SignalGraph, Effect, and the RabbitMQ adapter.
---

Use a Node.js ESM project. Set `"type": "module"` in its `package.json`. Use Node.js 22.19 or newer for the current CLI and its Effect Node dependencies.

Install Effect 4.1.5 or newer within Effect 4, and install SignalGraph. Add the RabbitMQ adapter in applications that publish or consume messages through RabbitMQ.

<CodeGroup>

```sh npm
npm install effect signalgraph @signalgraph/adapter-rabbitmq
```

```sh pnpm
pnpm add effect signalgraph @signalgraph/adapter-rabbitmq
```

</CodeGroup>

Next, follow the [RabbitMQ quickstart](/getting-started/quickstart/) or the [Cloudflare Queues guide](/adapters/cloudflare/). If you already have a schema, see the [config reference](/config/).
