title: Installation
description: Install SignalGraph core and adapter
---

<CodeGroup>

```sh npm
npm install signalgraph
```

```sh pnpm
pnpm add signalgraph
```

```sh bun
bun add signalgraph
```

```sh yarn
yarn add signalgraph
```

</CodeGroup>

## Adapter

SignalGraph is built up as multiple packages where each broker is represented by an
adapter package. You can learn more about them [here](../adapter/index.mdx).

The example below is using the [RabbitMQ adapter](/adapter/rabbitmq)

<CodeGroup>
```sh npm
npm install @signalgraph/adapter-rabbitmq
```

```sh pnpm
pnpm add @signalgraph/adapter-rabbitmq
```

```sh bun
bun add @signalgraph/adapter-rabbitmq
```

```sh yarn
yarn add @signalgraph/adapter-rabbitmq
```
</CodeGroup>
