SignalGraph generates a typed messaging client from Effect schemas. Declare your messages and consumers before running the generator. When the consumer starts, the RabbitMQ adapter declares the exchanges, queues, and bindings.

```ts title="src/schema/schema.ts"
import { Schema } from "effect";
import { consumer, message } from "signalgraph";

export const OrderCreated = message({
  name: "orders.created",
  schema: Schema.Struct({ orderId: Schema.String })
});

export const Billing = consumer({
  name: "billing",
  message: OrderCreated
});
```

The generated client exposes `client.ordersCreated.publish(...)` and `client.billing.handle(...)`, both typed from the same schema. The adapter handles transport and delivery. RabbitMQ is the supported broker.
