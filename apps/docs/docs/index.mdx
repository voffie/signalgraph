SignalGraph turns Effect schemas into a typed messaging client. Define each message and the consumers that subscribe to it, then run the CLI. At startup, the broker adapter uses those declarations to set up the messaging topology.

```ts title="src/schema/schema.ts"
import { Schema } from "effect";
import { consumer, message } from "signalgraph";

export const OrderCreated = message({
  name: "orders.created",
  schema: Schema.Struct({ orderId: Schema.String })
});

export const Billing = consumer({
  name: "billing",
  message: OrderCreated
});
```

The generated client gives you `client.ordersCreated.publish(...)` and `client.billing.handle(...)`, both typed from the same schema. The adapter handles transport and delivery. RabbitMQ is the supported broker.
