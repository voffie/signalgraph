---
title: Integrations
description: Add capabilities to a running SignalGraph client.
---

Pass integration layers through the `integrations` option on `client.listen()`. The client builds those layers before starting consumption and releases their resources when the listener's scope closes.

[Devtools](/integrations/devtools/) runs a local web app for inspecting SignalGraph message flows through OpenTelemetry. Custom integrations can use the `Integration` type exported by `signalgraph/integration`.
