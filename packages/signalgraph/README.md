# `signalgraph`

SignalGraph is a library for building maintainable, and type-safe message broker infrastructure in TypeScript.

The `signalgraph` package is the main entrypoint of the library. It provides the schema DSL and CLI to generate the client users interact with. It also the package that exposes the building blocks for each adapter and/or integration.

> FYI: SignalGraph is ESM-only. It needs `"type": "module"` set.

## Installation

```sh
npm install signalgraph
```
